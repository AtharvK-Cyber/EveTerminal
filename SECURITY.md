# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

The EveTerminal team takes security and network safety seriously. If you discover a vulnerability or potential exploit (such as escape sequence parsing crashes or buffer issues):

1. **Please do NOT report security vulnerabilities via public GitHub issues.**
2. Send a report via email or open a private GitHub security advisory.
3. Include detailed steps to reproduce the issue and the software versions affected.
4. We will acknowledge receipt of your report within 48 hours and work with you on a coordinated fix.
